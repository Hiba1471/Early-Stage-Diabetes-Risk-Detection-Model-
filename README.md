# Early-Stage-Diabetes-Risk-Detection-Model-
This project aims to enable early diabetes intervention by predicting risk from CDC behavioral survey data and identifying the key drivers of that risk. I built a LightGBM binary classification pipeline on a dataset with significant class imbalance — only 14% of patients had diabetes — applying SMOTE to oversample the minority class for more accurate predictions. I used SHAP TreeExplainer to surface the most influential risk factors at both the individual and population level, providing interpretable insights into what drives diabetes risk. After hyperparameter tuning and applying Youden's J statistic to set an optimal classification threshold, the model performed roughly three times better than a random classifier despite the challenging class distribution.
